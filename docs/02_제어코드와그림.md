## 2. 글꼴 B 문제
- 메뉴 창(NOTE)은 기본 글꼴 B, 대사 안 `{13}` 도 B 로 바꾼다. B 는 A 의 «앞 221자»만 있다.
- 원문 시스템 문장 중 221 이상 글리프를 쓰는 건 6개(母·警備隊員·杉田·通信機·が装備中·記録を選んでください) — B 창이 아닌 곳에서 쓰이는 것으로 보임.
- 한글은 음절이 칸 앞쪽에 몰리지 않으므로 **B 를 A 와 같은 칸 수로 늘려 같은 음절을 11×11 로 넣는다**(서술자 포인터로 이전 가능). 칸 확장 설계와 같이 한다.
